# Shopping List – Full MVP

Mörkt, mobilfokuserat inköpslistprogram med:

- **Frontend:** React + Vite + Tailwind CSS (port 5182)
- **Backend:** Express + SQLite via sql.js (port 8000)
- **Funktioner:** Lägg till varor, kryssa av som köpta, starra favoriter, arkivera i "Slutfört"-listan

## Kom igång lokalt

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend (ny terminal)
cd frontend
npm install
npm run dev
```

Frontend körs på `http://localhost:5182`, backend på `http://localhost:8000`.
